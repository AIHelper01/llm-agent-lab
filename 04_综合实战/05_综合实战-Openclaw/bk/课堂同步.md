6. 启动Qwen3:4B模型

```
(base) root@server5:~# conda activate env_vllm
(env_vllm) root@server5:~# CUDA_VISIBLE_DEVICES=0 \
vllm serve /workspace/models/Qwen/Qwen3-4B \
  --port 9991 \
  --served-model-name my_qwen3_4b \
  --tensor-parallel-size 1 \
  --gpu-memory-utilization 0.8 \
  --max-model-len 16384 \
  --max-num-seqs 8 \
  --dtype half \
  --enforce-eager \
  --trust-remote-code \
  --enable-auto-tool-choice \
  --tool-call-parser hermes \
  --reasoning-parser deepseek_r1 \
  --api-key YOUR_API_KEY
```

response.choices[0].message.content
