# Project conventions

- Prefix all newly developed MCP service names, client configuration keys, and
  primary server script filenames with `w-`. The `w` is the owner's name initial.
- Current example: display name `w-File Workbench MCP`, server name
  `w-FileWorkbenchMCP`, primary script `w-file_workbench_mcp_server.py`.
- Preserve existing launch compatibility and persisted data when renaming a
  service. Do not rename unrelated legacy MCP servers unless requested.
